# Campus BR - Phase 2 (multiplayer)
    npm install
    npm start          # http + websocket on :3000  (PORT env to change)
Open http://localhost:3000 in 2+ tabs. Same squad code = same squad (max 4). Blank code = auto squad.
Room starts a 15s countdown at 2+ players, up to 5 squads (20 players) per room; more rooms open automatically.
Controls: WASD, Shift sprint, Space jump, mouse look (click canvas). Offline mode: F = fly.
